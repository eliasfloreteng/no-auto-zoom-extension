No Auto Zoom

Privacy

No Auto Zoom collects nothing. There are no accounts, no analytics and no ads, and neither the app nor the extension makes any network requests.

What the extension reads

When you allow it on all websites, Safari warns that the extension can read and change the pages you visit, because it runs on every page. The only thing it looks at is the page's viewport tag, which tells Safari how far the page may zoom, and the only thing it changes is that tag.

What it keeps

If you turn it off for a site, the extension remembers that site's name so it stays off there. The list is kept in Safari's storage on your iPhone and is never sent anywhere.
