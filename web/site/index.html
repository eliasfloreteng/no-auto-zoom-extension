No Auto Zoom

Tap a text field. Safari stays put.

No Auto Zoom is a Safari extension for iPhone. It stops the page from zooming in every time you tap a search box or a form, so you don't have to pinch back out. Pinch-to-zoom keeps working.

No accounts, no analytics and no network requests. The list of sites you've turned it off for stays in Safari on your phone.

Why does Safari zoom in?

Safari zooms into any text field whose text is smaller than 16 pixels, so you can read what you type. Lots of sites use smaller text in their forms, so the page jumps every time you tap a field, and you're left pinching back out to see the rest.

A site can switch this off for itself by capping how far its page zooms. Safari ignores that cap when you pinch, so it only stops the automatic zoom. No Auto Zoom adds the cap to every page you open.

Questions

How do I stop Safari on iPhone from zooming in when I tap a text field?

Install No Auto Zoom, then turn it on under Settings › Apps › Safari › Extensions › No Auto Zoom and set All Websites to Allow. After that, Safari no longer zooms in when you tap a text field, a search box or a form.

Is there a setting in iOS that turns off the auto-zoom?

No. iOS has no switch for it, and Safari's Page Zoom setting doesn't turn it off. A website can turn it off for its own pages, and a Safari extension like No Auto Zoom can do the same on every site.

Can I still pinch to zoom?

Yes. Only the automatic zoom on tapping a field goes away. Pinch-to-zoom works as before on every page.

Does it work in Chrome or other browsers on iPhone?

No. Safari extensions only run in Safari.

Does it work on iPad?

Not yet. No Auto Zoom is for iPhone, with iOS 26.2 or later.

Is it free?

Yes. It's free and in beta, and you install it through Apple's TestFlight app.

What can the extension see?

Safari warns that it can read and change web pages, because it runs on every page. It only reads and changes the page's viewport tag, which controls how far the page may zoom. It collects nothing and makes no network requests.

Set up in a minute

  1. Install No Auto Zoom from TestFlight and open it.
  2. Tap Open Safari Extension Settings and turn on Allow Extension.
  3. Set All Websites to Allow, so it works on every site.
